# VibePlaylist AI

VibePlaylist AI — настольное приложение на Python/PyQt5, которое генерирует «живые» AI-плейлисты по описанию вайба и сохраняет их в аккаунт Яндекс Музыки. Под капотом — анализ артистов/жанров/настроений и умный подбор треков с топами артистов, похожими исполнителями, радио и mood-станциями (упрощённая логика в стиле Spotify AI Playlist).

## Установка
1. Клонируйте репозиторий и перейдите в каталог проекта.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Получение токена Яндекс Музыки
1. Авторизуйтесь в Яндекс Музыке в браузере.
2. Откройте инструменты разработчика и найдите запросы к `https://music.yandex.ru`.
3. В заголовках запросов найдите `Authorization: OAuth <TOKEN>` — это и есть ваш токен.
4. Запустите приложение. При первом старте введите токен; он будет сохранён в `~/.config/vibeplaylist/token.json`.

## Запуск
```bash
python run.py
```
После запуска появится GUI: введите описание вайба, нажмите «Создать плейлист» (статус покажет «генерируем как Spotify AI…»), оцените найденные треки и сохраните результат кнопкой «Сохранить плейлист в Яндекс Музыке».

## Как работает система вайбов
- Анализирует текст → выделяет артистов, жанры, муды (dark, neon, hype, chill и др.), вайбы, интенсивность.
- Валидация артистов через `client.search(..., type_="artist")`.
- Подбор треков совмещает:
  - топ-треки артистов,
  - похожих артистов и похожие треки,
  - радио/станции по артистам и mood-станции ротора,
  - перемешивание и ограничение до ~35 треков.
- Название формируется из главного вайба, жанра и артиста.

## Примеры подсказок
- `nettspend, playboi carti`
- `ночной неоновый вайб синтвейв`
- `агрессивный трэп для зала как у carti`
- `сделай грустную осеннюю атмосферу как в кино`

## Примеры названий плейлистов
- `Dark Winter Trap — Nettspend AI Mix`
- `Neon Night Synthwave`
- `Cold Emotional Trap Mix`
- `Dreamy Chill AI Playlist`

## Логирование
Все действия и ошибки пишутся в `app.log`. При сетевых ошибках или неверном токене отображаются уведомления в GUI.
