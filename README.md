# VibePlaylist AI

VibePlaylist AI — настольное приложение на Python/PyQt5, которое генерирует «живые» AI-плейлисты по описанию вайба и сохраняет их в аккаунт Яндекс Музыки. Под капотом — фазовый анализ промпта, извлечение артистов/жанров/настроений и многоступенчатый подбор треков (артисты → похожие → радио → mood-станции) со сглаженными переходами в стиле Spotify AI Playlist.

## Установка
1. Клонируйте репозиторий и перейдите в каталог проекта.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Получение токена Яндекс Музыки
1. Авторизуйтесь в Яндекс Музыке в браузере.
2. Откройте инструменты разработчика и найдите запросы к `https://music.yandex.ru`.
3. В заголовках запросов найдите `Authorization: OAuth <TOKEN>` — это и есть ваш токен.
4. Запустите приложение. При первом старте введите токен; он будет сохранён в `~/.config/vibeplaylist/token.json`.

## Запуск
```bash
python run.py
```
После запуска появится GUI: введите описание вайба, нажмите «Создать плейлист» (статус покажет «генерируем как Spotify AI…»), посмотрите разбор фаз запроса (артисты/жанры/муды), оцените найденные треки и сохраните результат кнопкой «Сохранить плейлист в Яндекс Музыке».

## Как работает система вайбов
- Анализирует текст → сегментирует фразы («сначала… потом…»), выделяет артистов, жанры, муды/вайбы, интенсивность, энергетику и темп.
- Валидация артистов через `client.search(..., type_="artist")`.
- Подбор треков совмещает:
  - топы артистов, похожих артистов и похожие треки;
  - радио по артисту и mood/genre станции ротора;
  - скоринг треков по совпадению жанра/вайба/энергетики;
  - сборку плейлиста по фазам с мягкими переходами (примерно 40/20/40 для двух фаз).
- Название формируется из ключевых вайбов и артистов фаз.

Все действия и ошибки пишутся в `app.log`. При сетевых ошибках или неверном токене отображаются уведомления в GUI.
