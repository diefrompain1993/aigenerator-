# VibePlaylist AI

VibePlaylist AI — настольное приложение на Python/PyQt5 для генерации музыкальных плейлистов по текстовому описанию настроения и сохранения их в аккаунт Яндекс Музыки.

## Установка
1. Клонируйте репозиторий и перейдите в каталог проекта.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Получение токена Яндекс Музыки
1. Авторизуйтесь в Яндекс Музыке в браузере.
2. Откройте инструменты разработчика и найдите запросы к `https://music.yandex.ru`.
3. В заголовках запросов найдите `Authorization: OAuth <TOKEN>` — это и есть ваш токен.
4. Сохраните токен в приложении при первом запуске. Он будет записан в файл `~/.config/vibeplaylist/token.json`.

## Запуск
Запустите приложение командой:
```bash
python run.py
```
При первом старте введите токен Яндекс Музыки. Затем опишите свой вайб, нажмите «Создать плейлист», просмотрите подобранные треки и сохраните плейлист в свой аккаунт.

Поддерживаются запросы вида:
- перечисление артистов через запятую (например, `nettspend, playboi carti`)
- описание вайба/жанра (например, `ночной неоновый синтвейв`)
- смешанные подсказки (например, `агрессивный трэп как у playboi carti`)

## Функционал
- Анализ текстового описания настроения и выделение тегов (жанры, эмоции, ключевые слова).
- Поиск подходящих треков в Яндекс Музыке.
- Автоматическая генерация названия плейлиста.
- Сохранение плейлистов в аккаунте пользователя.
- Логирование действий и ошибок в файл `app.log`.
