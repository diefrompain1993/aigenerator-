# VibePlaylist AI

VibePlaylist AI — десктопное приложение на Python, которое по текстовому описанию вайба подбирает треки через Яндекс Музыку и сохраняет готовый плейлист в вашем аккаунте.

## Требования
- Python 3.10+ и `pip`
- Доступ к интернету и валидный токен Яндекс Музыки
- (рекомендуется) изолированное окружение `venv`

## Установка
1. Склонируйте репозиторий и перейдите в директорию проекта.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r vibeplaylist/requirements.txt
   ```

## Получение токена Яндекс Музыки
- Сервис использует токен, который выдается в разделе «Устройства» / «Привязанные приложения» в личном кабинете Яндекс Музыки.
- Токен можно передать через переменную окружения перед запуском:
  ```bash
  export YANDEX_MUSIC_TOKEN="<ваш_токен>"
  ```
- Либо вставить его в поле «Токен Yandex Music» при первом запуске — приложение сохранит его в `~/.config/vibeplaylist/token.json` для последующих сессий.

## Запуск приложения
Запустите GUI следующей командой из корня репозитория (окружение должно быть активировано):
```bash
python -m vibeplaylist.main
```
После запуска:
1. Введите текстовое описание настроения/вайба.
2. Убедитесь, что поле токена заполнено (или задайте переменную окружения заранее).
3. Нажмите «Создать плейлист», дождитесь появления списка треков.
4. При необходимости скорректируйте результаты и нажмите «Сохранить плейлист в Яндекс Музыке».

## Логирование и кэш
- Логи выводятся в stdout и содержат информацию об инициализации клиента, поиске треков и создании плейлистов.
- Токен кэшируется в `~/.config/vibeplaylist/token.json` и подставляется при следующем запуске.

## Полезные команды
- Проверить, что зависимости установлены: `pip list | grep -E "PyQt5|yandex-music"`
- Удалить кэш токена: `rm ~/.config/vibeplaylist/token.json`
